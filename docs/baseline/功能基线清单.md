## 一、基线口径

| 状态 | 含义 | 处理要求 |
|---|---|---|
| `200` | 页面可用 | 必须保持；改造后不得退化 |
| `302` | 按设计跳转（模块入口、API 需登录、配置未完成回设置页、表单动作成功后回列表） | 属正常；但**跨模块跳转视为缺陷** |
| `404` | 路由存在但页面缺失 | 属功能缺口，列入补齐清单 |
| `500` | 服务端错误 | 视为故障，必须为 0 |
| `403` | 无权限页 | **禁止出现**；无权限一律隐藏入口 + 302 回本模块业务首页 |
